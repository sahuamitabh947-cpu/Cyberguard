# Training datasets

Not needed to run CyberGuard — the trained models are already in `detection-engine-cpp/models/`.
Only needed to retrain with `cg_train`.

| File / folder | Model | Source & licence |
|---|---|---|
| `sms.tsv` | phishing_text | UCI SMS Spam Collection (CC BY 4.0) |
| `enron_spam_data.csv` | phishing_text | Enron-Spam, Metsis et al. (via MWiechmann/enron_spam_data) |
| `urls_faizann.csv` | url_model | faizann24 malicious-URL dataset (GitHub) |
| `urls_phishing_recent.txt` | url_model | sample of Phishing.Database ACTIVE list (MIT) |
| `KDDTrain.txt`, `KDDTest.txt` | nids_model | NSL-KDD (UNB CIC) — KDDTrain+ / KDDTest+ |
| `psl.dat` | URL parsing | Public Suffix List (MPL 2.0) |
| `images/originals/` | image_manipulation | your own unedited photos (trainer synthesises the forgeries) |
| `audio/real/`, `audio/tts/` | audio_deepfake | real speech (LibriSpeech/Common Voice) vs synthetic speech |
| *(none)* | login_anomaly, log_anomaly | synthetic normal behaviour generated by the trainer |

```bash
cd datasets && bash fetch_datasets.sh
cd ../detection-engine-cpp && cmake -S . -B build && cmake --build build -j
./build/cg_train ../datasets models all          # or: text | url | nids | login | logs | image | audio
```
The trainer prints held-out metrics and writes them into each model file and `models/metrics_summary.json`
(shown on the **ML Models** page). Restart the engine to load new models.
